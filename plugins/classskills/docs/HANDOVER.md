## Current gameplay state

- Four classes: Warrior, Archer, Paladin, Mage.
- The selected class has its own saved profile: level, XP, unspent points,
  unlocked difficulty, and purchased nodes.
- Switching away stores the active class profile; switching back restores it.
- A new class starts at Level 1 with its starting point allocation.
- After Difficulty 3, switching class needs a Soul Shard. The selected profile
  is restored rather than deleted when returning later.
- DungeonForge's active class and live skill-point balance are synchronized to
  the active ClassSkills class profile.
- Outside a dungeon, players can use any ordinary weapon normally. Class
  passives, custom shots/casts, and F-key active abilities are dungeon-only.

## Progression

- Maximum level: **100**.
- First level-up cost: **100 XP**.
- Skill point total at Level 100: **200**.

Point schedule:

| Levels | Points per level |
|---|---:|
| 1–33 | 1 |
| 34–65 | 2 |
| 66–99 | 3 |
| 100 | 1 capstone point |

- Difficulties are level gated: every ten levels unlocks the next difficulty,
  up to Difficulty 9.
- Dungeon completion awards XP and independently rolls at most one Skill Shard
  and one Soul Shard.

## Skill tree

- DungeonForge owns the stationary shared-panel structure and node progression
  UI from `skills.yml`.
- ClassSkills maps its node IDs into the 40-node local effect catalogue:
  - `w1`–`w11` → weapon nodes
  - `a1`–`a14` → ability nodes
  - `s1`–`s14` → survival nodes
- The free external `root` node has no local stat effect.
- Local node IDs are class-prefixed, for example:
  `warrior_weapon_01`, `archer_ability_05`, `paladin_survival_14`.
- Weapon nodes grant Attack, survival nodes alternate Health and Armor, and
  Ability nodes contain passive ranks plus supporting stats.
- Ability node `a0` is the free, ungated Passive Rank I root. Difficulty 3
  unlocks `a1`, which raises the passive to Rank II; `a2`–`a5` raise it through
  Rank VI.

## Commands

- `/class` opens the custom holographic class picker.
- `/class <warrior|archer|paladin|mage>` selects directly.
- `/skills` by itself **does not open the old skill tree**; it directs the
  player to the in-world panel.
- `/skills levelup`, `/skills difficulty`, `/skills unlockdifficulty`,
  `/skills give`, `/skills testreset`, `/skills hardreset`, and
  `/skills focusdraw` remain available as utilities/admin commands.
- `/skillshard [player] [amount]` and `/soulshard [player] [amount]` are the
  direct shard-giving commands.

## DungeonForge integration

`DungeonForgeBridge.kt` dynamically resolves the DungeonForge API at runtime;
the DungeonForge API is not bundled in this plugin.

- Requires DungeonForge API v3 for dungeon lifecycle integration.
- Uses API v4 skill events/write methods when available.
- Handles dungeon completion XP/shards and difficulty entry gating.
- Synchronizes DungeonForge active class and live point balance with the active
  ClassSkills profile.
- Rejects an unlock event for a non-current local class before points are spent.

Important caveat: DungeonForge's API itself sends the generic message
`Another plugin refused unlocking ...` when a cancellable node unlock event is
cancelled. This text is generated by DungeonForge, not ClassSkills; suppressing
or customizing it requires a DungeonForge API/configuration change or packet
interception.

## Build

The Gradle build is configured to target Java 21. The local workflow has used
JDK 25 as the compiler with `-PbuildJdk=25` and Gradle offline mode.

```powershell
gradle build -PbuildJdk=25 --no-daemon --offline
```

Copy the resulting `build/libs/class-skills-<version>.jar` to `outputs/` for
handoff.
